Interactive figures for A Simplified Round-by-round Soundness Proof of FRI

Companion to A Simplified Round-by-round Soundness Proof of FRI by Albert Garreta, Nicolas Mohnblatt and Benedikt Wagner (ePrint 2025/1993).

The two tabs reproduce the paper's sketches of the error functions and its coloured prover message graph, with some parameters left for you to play with. The field size and rate of the code are fixed.

This page is designed for a desktop browser and is not optimised for mobile.

Error functions for \(t\) repetitions of the query phase

The following graphs represent the error functions as described in the paper. Recall that \(\gamma \in [0,1]\) is the distance parameter of the mutual correlated agreement event and \(\delta := \Delta(f_0, \mathcal{C}_0)\) is the relative Hamming distance between the input codeword and the initial code.

Drag the slider to move the trade-off parameter \(\theta\). Notice how small values of \(\theta\) improve the folding round error but deteriorate the query round error — increasing \(\theta\) has the opposite effect. You can also vary the number of repetitions of the query phase \(t\) to improve the query phase error.

0.500

The curve \(\varepsilon^{\mathsf{mca}}(\gamma) \) is the same illustrative placeholder used in the paper figure, not a real bound. Its main features are that it is small for small values of \(\gamma\) below the Johnson bound (\(1-\sqrt{\rho}\)) and is large for values beyond the capacity of the code (\(1-\rho\)). The behavior of this error between the Johnson bound and the capacity bound is the object of the "Proximity Prize", as studied by better.codes.

Advanced: varying the MCA bound

A better mutual correlated agreement bound keeps \(\varepsilon^{\mathsf{mca}}(\gamma)\) small for larger values of \(\gamma\), so the curve shoots up further to the right. A worse bound does the opposite.

Moving from "Default" to "Worse bound" illustrates what happens when parameters were set using conjectures about the MCA error that are later disproven. On the other hand, moving from "Default" to "Better bound" illustrates what happens when new results are established beyond the Johnson bound.

Prover message graph and its colouring

Click a node in \(\mathcal{L}_1\), \(\mathcal{L}_2\) or \(\mathcal{L}_3\) to mark the prover's fold at that point as dishonest (an \(\mathbf{X}\) means \(f_i(y) \neq \mathsf{Fold}(f_{i-1}, m_i, \alpha_i)(y)\)). Hover a node in \(\mathcal{L}_0\) to trace the verifier's query path.

The setting is identical to the paper: \(|\mathcal{L}_0| = 16\), there are \(k = 3\) folding rounds with folding factors \(m_i = 2\).

uncoloured \(\mathsf{green}\) (verifier's assertions pass) \(\mathsf{red}\) (some assertion on the path fails) X dishonest fold at this node

Rules: the bottom layer is always \(\mathsf{green}\). A node whose parent is \(\mathsf{red}\) is \(\mathsf{red}\). A node whose parent is \(\mathsf{green}\) is \(\mathsf{green}\) if the fold at the parent is honest, and \(\mathsf{red}\) otherwise. \(W_i\) is the set of \(\mathsf{green}\) nodes in \(\mathcal{L}_i\) that are not marked \(\mathbf{X}\).
